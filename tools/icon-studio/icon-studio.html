Heron Icon Studio - ribbon icons

One block per ribbon button, in ribbon order. "Today" is the icon in the add-in now; "New" rows are the new drawings. Left a light Revit ribbon, right a dark one. "32 as Revit shows it" = a plain 32 px file stretched by your Windows display scale (as Revit does today); "sharp" = drawn for your screen; "big" = the drawing itself, large. Style rule: STYLE.md.
