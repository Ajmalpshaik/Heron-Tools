# About panel

[Tool catalogue](README.md) > About

## About Heron

**What it does:** shows which Heron Tools version runs in this Revit, with the Revit and .NET versions, and links
to both Heron products (Heron Tools and Heron AI).

**When to use it:** to check which version you have before you report a problem, or after an update.

**How to use it:** Heron tab > About > **About Heron**. It works with no model open.

**What it changes in the model:** nothing - it reads nothing from the model.

Screenshot needed: the About Heron window.

## Revit versions

2020 to 2027.
