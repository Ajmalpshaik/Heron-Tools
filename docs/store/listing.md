## Description

Copy everything between the lines. It is under 4,000 characters (checked below).

---

Heron Tools is a free, open-source add-in for Autodesk Revit 2022 to 2027. It adds a Heron tab to the ribbon with everyday tools for BIM modellers and coordinators, so routine jobs take one click instead of many.

WHAT YOU GET

Quick
- Quick Menu: a tool wheel that opens at the mouse pointer with your favourite tools. Choose the slots, design, colour and effect.

View
- Filter Pro: one view filter for every value of a parameter, named and applied for you.
- Colorize: colour elements by value without making filters, with a way back.
- Reset Graphics: clear element or category overrides, and restore the last reset.
- View Crop: fit plan crops around the model; tick a box to set the annotation crop in the same run.
- 3D Section Box: fit the 3D view to a room, a section or a plan area in one click.
- Unhide All, Toggle Links and Highlight.

Datums
- Auto Dimension: chain and overall dimensions across grids and levels in one click.
- Reset Datums to 3D, Level Extents and Flip Bubbles.

Modify
- Match Elevation, Reassign Level (without moving elements), Pin / Unpin and Smart Selection.

Coordination
- Quick Clash: a Navisworks-style clash test inside a 3D view, in a window that stays open while you work.
- Element ID: find an element by ID, also in links.
- 3D Views by Workset and Link Workset.

BUILT TO BE SAFE
- One button press is one Undo step. If a run fails, it is rolled back and the tool tells you why.
- Your own graphic overrides are not lost without a way back.
- A greyed-out button means the tool does not work in the open view.

PRIVACY
Heron Tools collects no personal data and makes no internet connection. It saves a few small settings files on your own PC. Privacy policy: https://github.com/Ajmalpshaik/Heron-Tools/blob/main/PRIVACY.md
