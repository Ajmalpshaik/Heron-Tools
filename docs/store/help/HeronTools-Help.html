What Heron Tools is

Heron Tools is a set of everyday tools for Autodesk Revit users: view filters, colours, crops, datums, levels, pinning, clash checks, links and worksets, and a tool wheel at the mouse pointer. It is free and open source.

Rules every tool follows

  • One button press is one Undo step. If something fails, the whole run is undone and the tool says so in plain words. Press Ctrl+Z to undo a run.
  • Your own graphic overrides are never lost without a way back (each tool below says how).
  • A greyed-out button means the tool does not work in the view that is open. Its tooltip says which views it needs.
  • Distances in the windows are in millimetres.

Please read the disclaimer. These tools change live Revit models. Try a tool on a copy of a model first, and save before a large run.

Install and remove

  1. Install: download Heron Tools from the Autodesk App Store and run the installer Autodesk provides. Close Revit first. The installer adds Heron Tools to the Revit versions you have (2022 to 2027).
  2. Start Revit. If Revit asks whether to load the add-in, choose to always load it.
  3. Remove: close Revit, then uninstall Heron Tools from Windows Settings > Apps > Installed apps.
  4. Clear saved settings (optional): uninstalling leaves a few small settings files. Delete the folders %AppData%\HeronTools and %LocalAppData%\HeronTools. See the privacy section.

Where the Heron tab is

After you start Revit, a tab called Heron sits in the ribbon beside Revit's own tabs. Its panels, from left to right: Quick, View, Datums, Modify, Coordination, About.

The tools

| Quick panel

Quick Menu

Opens a tool wheel around the mouse pointer with your favourite Heron Tools buttons and Revit commands. Click it, then click a tool or press its number. Esc closes it. Tip: give the button a keyboard shortcut (File > Options > User Interface > Keyboard Shortcuts, search "Quick Menu").

The small arrow under the button opens Quick Menu Settings: which tool is in each slot (4 to 12 slots), and how the wheel looks (design, colour, effect, names, opening style, size). It changes nothing in the model.

| View panel

Filter Pro

Makes one view filter for every value of a parameter (for example one per system or size), names them and adds them to the view, or to views you pick. Pick categories, a parameter and values; check the name preview; press Apply to view. Each run is one Undo step.

Colorize

The same picks as Filter Pro, but the colour goes straight onto the elements as graphic overrides and no filter is made. Restore original puts back each element's own overrides while Revit stays open.

Reset Graphics

A drop-down: Reset Selected clears the overrides of selected elements; Reset Graphics... clears element and/or category overrides in this view or views you pick; Restore Last Reset puts back what the last reset cleared.

View Crop

Fits the crop region of plan views around their elements with a margin (300 mm as standard). It now has an Also turn on the annotation crop tick box: tick it and the same run also turns on the annotation crop and sets it a distance outside the crop, measured on paper (25 mm as standard). Works in floor, ceiling, structural and area plans. Views with a shaped (non-rectangular) crop are skipped and listed.

3D Section Box

One click fits Revit's own {3D} view to your work: select a room, space or zone; or a section; or drag a window in a plan. You stay in your view while the 3D view updates behind it. (This tool was called 3D Snapshot in early test versions.)

Unhide All

Shows everything hidden in the active view: turns Temporary Hide/Isolate off and unhides elements hidden one by one. Categories hidden in Visibility/Graphics stay as they are.

Toggle Links

Turns the RVT Links category off or on in the active view. Click again to bring the links back.

Highlight

Shows the selected elements in red and everything else in grey in the active view. Click again in the same view to put it back.

| Datums panel

Reset Datums to 3D

Puts grid and/or level ends in the active view back to their 3D extents: Grids, Levels or Grids and Levels.

Level Extents

Match Level Extents gives other levels the same 3D extents as a source level. Levels to Section Box stretches every level to the section box of the active 3D view.

Flip Bubbles

Swaps which end of a grid or level shows its bubble. Pick datums one at a time or window-select batches; Esc to finish.

Auto Dimension

On the Datums panel. Places a chain and an overall dimension row across the grids and/or levels of the active view, just inside their heads. Choose Grids, Levels or Grids and Levels; Settings sets the gaps, the ends, the dimension types and names to leave out. Select some grids or levels first to dimension only those. Works in plans, sections, elevations and their callouts; curved grids are left out and counted.

| Modify panel

Match Elevation

Gives other MEP elements the same centre, top or bottom elevation as a source element: Match Centre, Match Top, Match Bottom. Pick the source, then the targets; Esc to finish.

Reassign Level

Moves ducts, pipes, cable trays, conduits and free-standing families to another reference level without moving them in space. Choose the whole project or your selection, pick the To level, press Reassign. Anything that would move is put back and reported.

Pin / Unpin

Pins or unpins whole groups in one go: title blocks, views, legends, schedules, duct and pipe systems, equipment, grids, levels and more. In a workshared model, elements a colleague owns are left alone.

Smart Selection

Pick one element, then window-select: only elements of the same category stay selected. It only selects; it changes nothing.

| Coordination panel

Quick Clash

A clash test in the active 3D view, in a window that stays open while you work. Choose Selection A and B, then Hard and/or Clearance, and press Run. Clashes turn red and green and the rest goes grey. Click a clash to zoom, then Isolate, Show all or Select. Press Reset view when done (it also happens by itself before Save and Synchronize with Central).

Element ID

A drop-down. ID of a Picked Element shows an element's ID and which model it comes from, also in links. Find by Element ID finds and zooms to an element by its ID, in this model or a link. Both only read the model.

3D Views by Workset

In a workshared model, makes one 3D view per user workset, named after the workset and showing only that workset.

Link Workset

In a workshared model, puts Revit links and CAD imports on a workset (an existing one, or a new name you type).

About Heron

Privacy

Heron Tools collects no personal data and sends nothing over the internet. It saves a few small settings files on your own PC. Read the full privacy policy (https://github.com/Ajmalpshaik/Heron-Tools/blob/main/PRIVACY.md).

Support

A problem or an idea: open an issue on GitHub (https://github.com/Ajmalpshaik/Heron-Tools/issues). Say which tool, which Revit version, which view, what you did and what happened. Use Copy version details in About Heron. Please never attach a client model.
