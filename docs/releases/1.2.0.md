# Heron Tools 1.2.0

Released 2026-11-22. Revit 2020 to 2027. Full list of changes: [CHANGELOG.md](../../CHANGELOG.md).

> **Model Walk is DRAFT.** It compiles for every Revit year, but it has **not yet been tested in a real Revit**.
> Try it on a copy of a model first. The owner's Revit test (steps 1-62 in
> [model-walk-move-notes.md](../model-walk-move-notes.md)) is still to be done.

## What is new for a modeller

**Model Walk** (Heron tab, Coordination panel, 3D views only) - a new tool:

- Walk the live model in **first person** (W A S D and the mouse, five speeds, Fly, Pass-through, doors with E,
  Go to point, a low eye for ceiling voids, Measure, Snapshot).
- **Third person** (Q): a site worker in a yellow hard hat (1850 mm) stands, walks and runs with you. He is drawn
  on screen only - nothing is added to the model, no Undo step.
- **Quick snags**: in Snag mode, click snag after snag - each gets a picture and a red colour at once. Write the
  comments later in the pause menu (Esc). Everything goes to `Snags.csv` next to the model.
- **Inspect**, **Select** and **Hide** modes; **viewpoints** saved per model or as a real Revit 3D view.
- Your own element colours always come back: J, and before every Save and Sync with Central.
- Guide: [model-walk-guide.md](../model-walk-guide.md).

**Fixes in the other tools** (a full code review, issues #18-#37): Colorize, Quick Clash, Filter Pro, Reset
Graphics, Pin / Unpin, Flip Bubbles, Crop View, Reassign Level, Match Level Extents, 3D Views by Workset,
3D Snapshot, Quick Menu and the installer. Highlights:

- Restore / Reset view never wipes an override you set by hand (Colorize, Quick Clash, Filter Pro).
- Revit 2024+ 64-bit element ids are never cut to 32 bits.
- mm to feet is now exact (1 / 304.8); View Crop values move by less than 0.001 mm.
- Every window fits a small or high-scaling screen, so the bottom buttons are always reachable.

## Install or update

1. Download **HeronToolsInstaller.exe** from this release.
2. Close Revit (or let the installer wait for it - it never closes Revit).
3. Run it, tick your Revit versions (2020 to 2027), press **Install**. This also updates 1.0.0 / 1.1.0 - there is no
   separate Update. Your old install is kept in `%LocalAppData%\HeronTools\install-backup\<year>`.

No administrator rights needed. The installer is **not code-signed yet**, so Windows SmartScreen may warn on the
first run (More info > Run anyway).

## Check the download

`SHA256SUMS.txt` on this release holds the SHA-256 of the installer. In PowerShell:

```powershell
Get-FileHash .\HeronToolsInstaller.exe -Algorithm SHA256
```

The hash must match the line in `SHA256SUMS.txt`.
