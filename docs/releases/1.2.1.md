# Heron Tools 1.2.1

Released 2026-11-22 as a **pre-release**. Revit 2020 to 2027. Full list of changes:
[CHANGELOG.md](../../CHANGELOG.md).

> **Model Walk is still DRAFT.** These fixes come from the owner's first test on a big project with linked models.
> They compile for every Revit year but have **not yet been tested in a real Revit**. Try them on a copy of a model
> first. Test steps 70-86 in [model-walk-move-notes.md](../model-walk-move-notes.md) cover them.

## What changed in Model Walk

- **Third-person character in a big model:** he now shows in projects far from Revit's internal origin. If Revit's
  own near cut hides him, the walk says so once instead of showing nothing.
- **Building no longer cut away:** a walk that starts outside the walk view's section box switches that box off
  (walk view only, one Undo step) and far clipping is switched off. Your own 3D view is never changed.
- **No annotation in the walk view:** levels, grids, scope boxes, reference planes, marks, tags, dimensions and text
  are hidden in the walk view only, and a view template is taken off it.
- **Doors in linked models** (and doors with a nested door panel): the door hint shows and E goes through.
- **Snags on linked elements:** a red box is drawn on screen and in the snag picture, because Revit cannot colour a
  single element inside a link. Hide on a linked element says so plainly. Select works inside a link on Revit 2023
  and later.
- **Jump:** Space jumps while walking (Settings: Jump height, standard 500 mm, 0 = off). It stops under a slab or
  duct and lands on steps. Space still rises in Fly and Pass-through.
- **Start on a roof:** the location line says "on a roof (outside)" and the walk tells you once how to get inside.
- **Readout:** "Something Revit could not name" now names the link it is in.
- **F12** shows a second line for the character: drawn or why not, the near cut, the section box and where his feet
  are. Please read it out if the character is still missing.

## Install or update

Full guide: [install.md](../install.md). Every tool explained: [tool catalogue](../tools/README.md).

1. Download **HeronToolsInstaller.exe** from this release (under **Assets**).
2. Close Revit (or let the installer wait for it).
3. Run it, tick your Revit versions (2020 to 2027), press **Install**. This updates 1.2.0 and older.

No administrator rights needed. Not code-signed yet, so Windows SmartScreen may warn on the first run
(More info > Run anyway).

## Check the download

`SHA256SUMS.txt` on this release holds the SHA-256 of the installer. In PowerShell:

```powershell
Get-FileHash .\HeronToolsInstaller.exe -Algorithm SHA256
```
